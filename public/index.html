ABOUT THE PROJECT

BloodLink

BloodLink is a student-friendly full-stack project that demonstrates how a frontend can communicate with a Node.js backend and store donor data.

Project Features

  • Donor registration
  • Blood group and city search
  • Availability management
  • Persistent JSON data storage
  • REST API using Express
